## Replacement playbook (apply per occurrence)

Apply the 5 rules from `260513-g96-RESEARCH.md` in priority order:

1. **Aside-between-dashes with internal commas / lists / code spans → wrap aside in parentheses.**
   - Example (clipify.mdx:27):
     - Before: `Content creators sit on hours of long-form footage — podcasts, streams, YouTube VODs — and repurpose it`
     - After: `Content creators sit on hours of long-form footage (podcasts, streams, YouTube VODs) and repurpose it`

2. **Aside-between-dashes, short noun phrase, no internal commas → comma pair.** (Rare in this codebase; most asides have internal punctuation.)

3. **Trailing-dash elaboration where the second clause is an independent sentence → period + capital-letter new sentence.**
   - Example (seatwatch.mdx:28):
     - Before: `The challenge was not just speed — it was reliability at scale.`
     - After: `The challenge was not just speed. It was reliability at scale.`

4. **Trailing-dash elaboration where the second clause defines/specifies (no independent verb) → colon.**
   - Example (solsniper.mdx:34):
     - Before: `slippage to guarantee exit — strictly worse than a clean STANDARD sell in the good case`
     - After: `slippage to guarantee exit: strictly worse than a clean STANDARD sell in the good case`

5. **Series-introducing dash → colon.**
   - Example (nfl-predict.mdx:30):
     - Before: `three external sources — games via \`nflreadpy\`, odds via The Odds API, and weather via Open-Meteo`
     - After: `three external sources: games via \`nflreadpy\`, odds via The Odds API, and weather via Open-Meteo`

6. **Fallback: if any rule produces clunky output, rewrite the sentence.** Jack's voice is dense, declarative, first-person, technical. Do not soften with "which is" / "and this means" / semicolons-as-stealth-em-dashes.

## Hard rules

- **DO NOT** edit any line in the frontmatter block (between the two `---` lines at the top of each file).
- **DO NOT** edit lines that don't contain U+2014 (em dash). Pre-existing en dashes `–` (U+2013) and hyphens are out of scope.
- **DO NOT** add or modify Markdown headings (`## Problem`, `## Approach & Architecture`, etc.) or list structure.
- **PRESERVE** all inline code spans (backtick content), all arrow characters (U+2192 `→`), all unicode arithmetic (`×`), all en dashes used as numeric ranges (`2–5`).
- **PRESERVE** sentence meaning. The rewrite must say what the original said.

## Approach per file

For each of the 6 MDX files:
1. Read the full file.
2. Locate each U+2014 in the body (after the closing `---`).
3. For each occurrence, identify which rule applies (1-5 above; rule 6 fallback).
4. Compose the rewrite. Read the surrounding 1-2 sentences if needed to keep prose flowing.
5. Apply via Edit with the full sentence (or paragraph if shorter is ambiguous) as `old_string` and the rewritten version as `new_string`. Em dash alone is never unique enough to disambiguate; always include several words of context.
6. After all edits in the file, run `Grep '—' <file>` and confirm only `chatSummary` (line 5) remains, with NO other matches.
