<!-- M5 fix: multi-line regex -->

The original `<script\s+is:inline[^>]*>[^<]*pageswap[^<]*<\/script>` pattern uses `[^<]*` which matches "any char except `<`" — but the raw script body (per B5) spans multiple lines AND may contain `<` characters within the JS body (e.g., comparisons like `if (x < 5)`). Use `[\s\S]*?` (lazy match across newlines) instead:

```regex
/<script\s+is:inline[^>]*>[\s\S]*?pageswap[\s\S]*?<\/script>/
```

The `*?` lazy quantifier prevents the regex from greedily swallowing past the closing `</script>` tag.
