# Phase 22 — UI Design Contract

> Visual and interaction contract for the Experience surface (EXP-02..EXP-05). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **This phase does not invent a design system.** It reuses the LOCKED editorial contract in `design-system/MASTER.md` and mirrors the existing Projects surface (`src/pages/projects.astro`, `src/pages/projects/[id].astro`, `src/components/NextProject.astro`). ## Spacing Scale

All values transcribed from MASTER.md §4 and the mirrored Projects patterns. No ad-hoc spacing — reuse these only (all multiples of 4).

| Token | Value | Usage |
|-------|-------|-------|
| xs | 8px | List-item gaps (`li` margin-bottom), tight stacks |
| sm | 12px | Inline link-row gap (external-links / back-link gap); Balfour cue spacing |
| md | 16px | Default block spacing — meta→title, title→tagline, paragraph rhythm, prose h2 bottom |
| lg | 24px | Section-header rule bottom margin, prose list padding-left, work-row grid gap |
| xl | 28px | Row vertical padding (`WorkRow` `padding: 28px 0`) |
| 2xl | 48px | Prose h2 top margin; detail-page back-link slot vertical padding (displaces `NextProject`'s 48px) |

Layout tokens (MASTER §2.2, applied only via `Container.astro`): `--container-max 1200px`; horizontal padding `--pad-desktop 48px` (≥1024), `--pad-tablet 32px` (<1024), `--pad-mobile 24px` (<768).

Section rhythm (MASTER §4.2, via `.section` class): `margin-top` 160px ≥1024 / 96px <1024 / 72px <768.

Exceptions: none. If the asymmetric two-tier layout (D-04) or the Balfour "Earlier" cue (D-06) needs a value not listed, frontend-design selects from MASTER's scale — no new tokens.

| Role | Class | Size | Weight | Line Height | Use in this phase |

## Color

The ENTIRE palette is MASTER §2.1's six hex tokens. No new colors, no `oklch`, no gradients, no rgba, no dark theme (MASTER §2.3 lock).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FAFAF7` `--bg` | Page background — `/experience` and `/experience/[id]` |
| Secondary text (30%) | `#0A0A0A` `--ink` / `#52525B` `--ink-muted` / `#A1A1AA` `--ink-faint` | Body/headings `--ink`; meta lines + inactive nav `--ink-muted`; dates/stack/"Earlier" cue + section counts `--ink-faint` |
| Surface/dividers (30%) | `#E4E4E7` `--rule` | Row borders, section rule, back-link top border, any bordered-block treatment |
| Accent (10%) | `#E63946` `--accent` | See reserved list below |
| Destructive | not applicable | No destructive actions in this phase |

Accent reserved for (MASTER §7 signal rule — "if a user can't click it, it can't be accent"):
- Active nav-link underline (the new `experience` entry when on `/experience` or `/experience/[id]`)
- "Read the full case study →" link hover (color/underline to accent)
- Back-to-summary mono link hover (D-02)
- Focus rings on every interactive element
- The `→` / `←` arrow reveal on the summary link and back link (opacity 0→1, 120ms, matching `WorkRow`/`NextProject`)
- MDX inline links inside `.prose-editorial` (existing `:global(a)` accent rule)

Accent NEVER on (MASTER §7.2): the Balfour entry (non-linked — no accent anywhere on it), body text, dividers (`--rule` owns those), the "Earlier" cue label, decorative arrows on non-interactive elements, any surface fill/banner/panel.

## Interaction & Component Contract (phase-specific)

Reuse-over-invention. Detected analogs and how each is adapted:

| New surface | Mirrors | Adaptation |
|-------------|---------|------------|
| `src/pages/experience.astro` (listing) | `src/pages/projects.astro` | `getCollection("experience")` → `sortExperienceEntries()` (reverse-chron, `src/lib/experience.ts`); wrap in `Container` + `.section`. **Not** a uniform `WorkRow` list — asymmetric two-tier (D-04): Holloway rich featured summary, Balfour lighter "Earlier" entry. Exact form → frontend-design. |
| `src/pages/experience/[id].astro` (deep-dive) | `src/pages/projects/[id].astro` | `getStaticPaths` filters `hasCaseStudy === true` (only Holloway builds; Balfour builds none — D-01). `render()` + `.prose-editorial` wrapper + scoped `:global()` MDX overrides copied verbatim. Meta = `dateRange · techStack`. H1 = "Holloway Company". Tagline = `.lead` summary. **Omit** the external-links row (confidential contract — D-07). **Replace** `NextProject` with the D-02 back link. |
| Nav entry | `Header.astro` + `MobileMenu.astro` | Add `experience` FIRST in both parallel `navLinks` arrays (D-03). `isActive` = `currentPath.startsWith("/experience")` (covers the detail route, mirrors `/projects`). Preserve MobileMenu focus-trap / `inert` behavior untouched. Active link gets MASTER §5.1 accent underline (1.5px, offset 6px). |
| Back-to-summary link | `NextProject.astro` link idiom (displaced, not reused) | Mono text link, hover→accent + arrow opacity reveal (120ms ease, no translate). At both top (under header) and bottom (the slot `NextProject` occupied). D-02. |

Interaction states (MASTER-locked):
- **Hover:** functional color transition only (`transition-colors`) + arrow opacity 0→1 over 120ms (WorkRow/NextProject pattern). No scroll-triggered animation (MASTER §8; MOTION.md governs the only allowed root fade).
- **Focus:** visible ring on every interactive element — `outline: 2px solid var(--accent); outline-offset: 2px` per the phase constraint. (Note: existing `NextProject`/prose analogs use `outline-offset: 4px`; executor/frontend-design reconcile to a single consistent offset — flag, not a blocker.)
- **Balfour:** no hover/focus affordance (non-linked, structurally enforced by the D-01 `hasCaseStudy` filter — no detail route exists).

Analytics / instrumentation (D-11): the deep-dive page adds the 4 Phase-15 scroll-depth sentinels (`data-percent` 25/50/75/100, `aria-hidden`) with `article { position: relative }`, feeding `src/scripts/scroll-depth.ts`. No new event types. The `/experience` summary page gets NO sentinels (short page).

Chat-surface invariant (SC5): nav edits live in `Header.astro`/`MobileMenu.astro` (BaseLayout children). Prefer page-scoped `<style>` over `global.css`. If `global.css` or `BaseLayout.astro` is touched, run the D-26 chat-surface battery and hold the D-15 SSE byte-identical anchor. `astro check` stays 0/0/0.
